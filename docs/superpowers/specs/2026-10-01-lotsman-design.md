# Лоцман — дизайн

Дата: 2026-10-01. Подход 1 из обсуждения: переключатель из четырёх стратегий с
«обучающимся» мозгом в P-памяти. Имя рабочее.

## Цель и критерии

- **Первый сезон (до заморозки 02.10, 00:00 UTC).** Первое место на хилле первого сезона в
  среднем по 64 случайным раскладкам, с отрывом от S30 больше погрешности. Тогда одна
  проверка на копии хилла и подача. Подбор раскладки (перебор имён, комментариев,
  сдвигов) не делаем.
- **Второй сезон и дальше.** Тот же боец без правки констант:
  1. хилл первого сезона на параметрах второго (8192, 512 раундов, 65 536 циклов,
     длина 128, дистанция 128), строка `;assert CORESIZE == 8000` у бойцов поля убрана;
  2. тот же хилл на 8000;
  3. наш набор архетипов (камни, импы, бумаги, сканеры, зачистки, переключатели) на 8192 и
     на простом 8191;
  4. публичные бенчмарки сообщества (если удастся скачать; только для замеров, нигде не
     публикуем).
  Успех: первое место на поле 1, не ниже третьего на остальных, и ни один соперник не
  выигрывает у него больше раундов, чем проигрывает.

## Ограничения

- Не больше 100 команд — собирается на хилле любого из наших сезонов.
- Ни одного прибитого числа ядра: всё через CORESIZE, PSPACESIZE и другие константы хилла
  (cw их поддерживает, как pMARS; в выражениях есть `*`, `/`, `%`, сравнения). Без
  `;assert` на размер ядра.
- Код целиком наш: классические схемы теории, написанные заново. Чужого кода с хилла
  нет (сканер Ледохода, дистанции Позитива не берём).

## Устройство

Порядок в файле: мозг (точка входа `ORG`), камень, сканер с общим ковром, данные, бумага —
последней: её копии уходят дальше по ячейкам, а не накрывают мозг.

### Стратегии

0. **Бумага Silk.** 2^k процессов (k = 5), два каскада `SPL @0` / `MOV }-1, >-1`, бомба,
   убывающий `MOV`, `JMP @0, j`. Дистанции и прыжок — доли CORESIZE, подбираются заново.
   Бомба против импов: `DAT <I3, <2·I3`, где I3 = ((3 − CORESIZE % 3) · CORESIZE + 1) / 3 —
   шаг трёхточечного импа (2667 на 8000, 2731 на 8192, 5461 на 8191).
1. **Сканер.** Сравнение пар ячеек (`SNE.I`) с шагом — долей CORESIZE; находка → ковёр
   `SPL 0` от находки, затем вечный проход `DAT` по ядру, свой код (длина бойца) — мимо.
2. **Зачистка.** Тот же ковёр `SPL 0`, затем `DAT`, но сразу и по всему ядру, без поиска
   (две команды поверх сканера).
3. **Невидимый камень.** Бомбы `DAT $0, $0` — их сравнение пустой ячейки не отличает; три
   видимые ячейки тела; шаг — кратный 4 и взаимно простой с CORESIZE / 4 (на ядре, где
   это невозможно, — взаимно простой с CORESIZE и с остановкой по счётчику, чтобы не
   бить по себе).

### Мозг: «многорукий бандит»

P-память: ячейка 0 — итог прошлого раунда (−1 до первого, 0 поражение, 1 победа, 2 ничья).
Своё: номер стратегии `a`, суммы очков `s[0..3]` и числа раундов `n[0..3]` против текущего
соперника, с ячейки `KEY`.

Каждый раунд:
1. Прочитать `a`; вне 0..3 — сбросить в 0 (защита от испорченной P-памяти).
2. Если раунд не первый: `s[a] += 3 / 1 / 0` за победу / ничью / поражение, `n[a] += 1`.
   Когда `n[a]` доходит до `CAP` (16), `s[a]` и `n[a]` делятся пополам — старые раунды
   весят меньше, переключатель соперника заметен.
3. Выбор:
   - победа — остаться на `a`;
   - иначе, если есть стратегия с `n < E` (E = 2), — следующая такая по порядку 0, 1, 2, 3
     (проба);
   - иначе — стратегия с лучшим средним `s/n` (сравнение `s_i · n_j` с `s_j · n_i`, без
     деления); при равенстве — бумага, затем меньший номер.
4. Записать `a`, `s[a]`, `n[a]` (STP) один раз за раунд и затереть свои `STP` — бродячий
   процесс не запишет мусор посреди раунда.
5. Перейти на стратегию `a`.

Параметры генератора: `E`, `CAP`, `KEY`, порядок проб, константы стратегий, `force=N`
(только стратегия N — для таблицы силы стратегий и тестов).

## Проверка

- **Сборка:** cw собирает бойца на 8000, 8192 и 8191, длина ≤ 100.
- **Мозг:** тестовая сборка, где стратегия N против неподвижного соперника даёт свой исход
  (0 — гибнет сразу, 1 — ничья, 2 — быстрая победа, 3 — победа позже). По `cw trace`
  восстанавливается выбор мозга в каждом раунде и сравнивается с моделью мозга на Python.
- **Стратегии:** режим `force=N` против поля — таблица силы каждой стратегии против каждого
  соперника; слабые доводятся.
- **Боец:** `cw versus --hill` по случайным раскладкам; корона — среднее по 64 раскладкам
  на независимой соли (`crown.py`), отрыв больше погрешности.

3. Настройка мозга (`E`, `CAP`, порядок проб) и дистанций бумаги; корона на 64 раскладках —

## Риски

- Мозг — самая хрупкая часть (ошибка в P-памяти тихо портит выбор): поэтому тест по
  трассировке до любых замеров.
- Каждая стратегия меньше отдельного бойца; против лучших бумаг Silk останутся ничьи.
- Срок: если к ночи боец не сильнее S30 в среднем, первый сезон не трогаем.

## Итог реализации (01.10, вечер)

Устройство разошлось с замыслом выше. Причины меряны, не предположены.

- **Две стратегии, не четыре.** Камня в бойце нет. Зачистка ни против одного соперника хилла не
  была лучшей стратегией, поэтому убрана.
- **Мозг-«бандит» снят.** Средние со сравнением через произведения вели себя хорошо в
  симуляции, а на хилле проиграли бумаге. Хилл — сплошь переключатели с P-памятью: проба
  сканера сбивает им режим на много раундов вперёд. На восьми переключателях пробы стоили
  ~100 очков, против бумаги без выбора ~700 на всём хилле. Модель с неизменными долями
  этого не видит.
- **Мозг стал «серией ничьих»,** как у Постового. Сканер пробуется только после 9 ничьих
  бумаги подряд: доверие 2, победа +1 (до 9), ничья или поражение −1; без доверия — бумага,
  а следующей пробе нужно вдвое больше ничьих. После победы бумаги первые 4 инструкции только
  читают P-память.
- **P-память пишется только в начале раунда.** Каждая стратегия первой инструкцией запускает
  стиральщик всех STP; сам он не пишет ничего. Все грабли найдены опытом:
  - фоновый счетовод под 32 процессами бумаги получает 1/33 тактов, и соперник успевает
    затереть его данные до записи;
  - нестёртые STP исполняют «бродячие» процессы;
  - флаг в общей с произведением ячейке при произведении 1 убивал старт раунда.
- **Сканер:** три пары проб за проход и выбор верхней пробы, если нижняя пуста.
  - Ковёр останавливается, когда указатель доходит до себя (идея Ледохода, neva-sandbox; в
    тексте бойца указано).
  - DAT-проходы чистят и собственное тело, кроме цикла очистки: копии чужой бумаги прятались
    в нашем мёртвом коде, и это давало 1736 → 1977 очков против четырёх бумаг.
  - Шаг 2803 и зазор 200 на 8000 найдены своим перебором: 2144 очка против 2154 у Ледохода
    на тех же бумагах.
- **Бумага:** 32 процесса; расстояния 2365 и 3240, прыжок −1549 (на 8000; в файле — доли
  CORESIZE). Лучшее второе расстояние сначала вышло 1869. Это почти 1870 Позитива, и в сетку я
  взял его сам, зная по Постовому, — против ограничения выше. Перебор без окрестности 1870
  нашёл 3240: на двух свежих солях 8862 и 8845 против 8812 и 8762 у 1869. Прыжок подобран
  заново под 3240. Корона полного бойца от этого выросла ещё на ~+115.
- **Результат на хилле первого сезона.** С бумагой 1869/−1349 корона у S30 по среднему на
  случайных раскладках отбиралась с отрывом +124…+215 (семь независимых солей, 32–64
  раскладки). На копии живого хилла по хешу, по которому считается итог первого сезона,
  каждая из двух версий проверена по одному разу, обе вторые: −8 и −71. С бумагой
  3240/−1549 отрыв по среднему +271 и +364 (две соли по 64 раскладки). Под хеш не
  подбираем: решение — по среднему, на копии одна итоговая проверка.
