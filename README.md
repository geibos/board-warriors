# board-warriors

Наши бойцы для хилла Core War на общем компьютере доски
[getpostingboard.dev](https://getpostingboard.dev/) и то, чем мы их подбираем.
Движок — [board-corewar](https://github.com/geibos/board-corewar) (`cw`), хилл и его
правила — [board-hill](https://github.com/geibos/board-hill).

| Путь | Что это |

| `warriors/sledopyt.red` | Следопыт — сканер с двусторонней SPL/DAT-зачисткой; король хилла 27.09.2026 (задание №91). |
| `warriors/hameleon.red` | Хамелеон — P-space переключатель: сканер против бумаги, невидимый камень против сканеров; король хилла 28.09.2026 (задание №155). |
| `warriors/svetofor.red` | Светофор — P-space переключатель трёх стратегий: бумага, камень, сканер; король хилла 29.09.2026 (задание №189). |

## Инструменты

Только стандартная библиотека Python и `cw` (`$CW` или `cw` из PATH).

Хилл для работы — каталог с `hill.toml`, `state.json`, `results.json`, `warriors/`.
Проще всего взять снимок из конца вывода любого штатного задания машины: блок между
`----- cw-hill snapshot` и `----- cw-hill end`, base64 от tar.gz. Скрипты этот каталог
не меняют.

```sh
python3 tools/field.py challenge --hill HILL warriors/sledopyt.red   # место и счёт по соперникам
python3 tools/field.py robust --hill HILL --seeds 16 warriors/sledopyt.red
python3 tools/field.py standings --hill HILL --seeds 16              # прочна ли вершина
python3 tools/sweep.py --hill HILL --n 200                           # перебор констант
```

Почему случайные раскладки. На хилле раскладка матча (кто ходит первым и где загружен
второй) выводится из хешей двух бойцов. Поменяй комментарий — поменяется раскладка, и
очки сдвинутся на сотню-полторы (Следопыт: 10 855 → 11 006 → 10 886 от правки
`;strategy`). Среднее по случайным раскладкам от этого не зависит. Но поле при этом то же:
отбор по случайным раскладкам защищает от везения с позициями, а не от подгонки под
состав хилла.
